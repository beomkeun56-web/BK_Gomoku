⚙ API 설정

게임은 당신이 고른 LLM이 게임 마스터(GM) 역할로 진행합니다. 제공사를 고르고, 모델과 API 키를 입력하세요. 키는 이 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다.

웹폰트는 선택 즉시 불러와 모든 기기에서 동일하게 보입니다. 궁서체·바탕은 기기에 설치된 글꼴을 사용합니다.

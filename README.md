# 국가의 시대 — 텍스트 국가운영 시뮬레이션 🇰🇷

당신이 한 나라의 지도자가 되어, 매 분기 내려지는 결정으로 **국력·경제·군사·외교·민심**을 움직이는 텍스트 국가운영 게임입니다. AI 게임 마스터(GM)가 선택에 따라 세계를 전개합니다.

▶ **플레이: GitHub Pages 주소** (예: `https://<사용자명>.github.io/BK_Gomoku/`)

## 특징
- **제공사 선택** — OpenRouter · Google Gemini · Anthropic Claude 중 골라 본인 API 키로 플레이
- **모델 자동 불러오기** — 키 입력 후 사용 가능한 모델 목록을 받아 선택 (직접 입력도 가능)
- **실시간 스탯 시각화** — 상단 HUD에 5대 스탯 막대그래프 + 날짜·분기·턴 표시
- **팝업 선택지** — 매 턴 3개 선택지를 버튼으로, 직접 행동 입력도 가능
- **스트리밍 출력 / 마크다운 렌더링** — 표·인용·제목까지 게임처럼 표시
- **저장 / 이어하기** — 진행은 브라우저에 자동 저장, 스냅샷으로 다른 기기 이전 가능
- 검은 배경의 전략 콘솔 스타일 UI, 모바일 대응

> API 키는 **당신의 브라우저(localStorage)에만 저장**되며 별도 서버로 전송되지 않습니다. LLM API 호출은 브라우저에서 각 제공사로 직접 이뤄집니다.

## 사용법
1. 사이트 접속 후 **⚙ 설정**에서 제공사·API 키를 입력하고 **모델 불러오기** → 모델 선택 → 저장
2. **게임 시작하기** 버튼 → 시작 프리셋(현대 대한민국 / 권력의 길 / 근대 조선 / 직접 설정) 중 선택
3. 매 턴 팝업 선택지를 누르거나 직접 행동을 입력해 진행
4. `상태`·`국정과제`·`저장`·`삽화`·`이어하기` 등 명령어 지원

## 로컬 실행
정적 단일 파일입니다. `index.html`을 브라우저로 열거나:
```
python3 -m http.server 8000   # → http://localhost:8000
```

## 배포 (GitHub Pages)
저장소 **Settings → Pages → Source: `main` 브랜치 / 루트(`/`)** 로 설정하면 `index.html`이 게임으로 게시됩니다.

## 참고
- 기존 오목 게임은 [`gomoku.html`](./gomoku.html) 로 보존되어 있습니다.
- Anthropic 직접 호출은 브라우저 CORS 허용 헤더를 사용합니다. 제공사별 정책/요금은 각 콘솔을 확인하세요.
